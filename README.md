# How Do You Know Your Agent Is Wrong?

A standalone, styled article for GitHub Pages. No framework, package
installation, analytics, external fonts, or build step. The repository root
is the website. Companion piece to
[System Prompt Is All You Need?](https://br0kensmi1e.github.io/system-prompt/).

## Preview locally

```bash
open index.html
```

`index.md` is the markdown source draft; `index.html` is the published page.
